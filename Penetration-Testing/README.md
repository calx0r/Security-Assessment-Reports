## Reporting Approach

Penetration testing reports are structured to clearly communicate:

- **Finding** — The security weakness identified during testing
- **Severity** — The assessed level of risk
- **Description** — The technical condition that created the weakness
- **Impact** — What successful exploitation could allow
- **Evidence** — Supporting technical validation
- **Remediation** — Actionable guidance for addressing the issue
